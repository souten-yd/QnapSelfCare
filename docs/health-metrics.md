# ダイエット評価とからだの指標：調査・設計・妥当性評価

Home画面の「ダイエット評価とからだの指標」カードとサマリー文の根拠です。計算は `health_metrics.py`（API: `GET /api/wellness/metrics?user_id=`）にあります。日付の区切りは既存のエネルギー計算と同じ日本時間（JST）です。

## 1. 使えるデータ

| データ | 出どころ | 主な誤差要因 |
|---|---|---|
| 体重・体脂肪率・内臓脂肪レベル・BMI | オムロン体組成計（BLE/CSV/手入力） | 体重は日内変動（水分・食事）SD 0.5〜1 kg、体脂肪率は生体インピーダンス推定 |
| 血圧・脈拍 | オムロン血圧計 | 測定ごとのばらつき（収縮期 SD 約8 mmHg） |
| 歩数・距離・活動エネルギー・心拍・血中酸素・睡眠ステージ | Apple Health（ショートカット取り込み） | ウォッチの推定値、記録元の重複 |
| 摂取kcal・活動係数・減量計画 | アプリ内の入力 | 入力漏れ、自己申告の過少 |

## 2. 調査した指標と採否

有用性＝ダイエットや健康管理の判断・行動に直結するか。妥当性＝基準の根拠の強さと、このアプリのデータで正しく推定できるか。

| 指標 | 判定基準（根拠） | 有用性 | 妥当性 | 採否 |
|---|---|---|---|---|
| 減量ペース | 週に体重の0.25〜1.0%を適正、1.0%超は速すぎ。肥満症診療ガイドライン2022は現体重の3%以上の減量を目標とする。急速な減量を避けるため、週に体重の1%（多くの人で0.5〜1 kg）以内を上限とした | 高 | 高（28日回帰で誤差±0.11 kg/週） | 採用 |
| 減量の中身（脂肪の割合） | 一般的な食事減量では除脂肪量の減少が10〜30%（いわゆる「1/4ルール」の再検討文献）。脂肪70%以上を良好 | 高（筋肉を落とすダイエットを早期に検知） | 低〜中（BIAの誤差が大きく、8週間・3 kg以上の減量が必要） | 条件付き採用（信頼度 低と表示） |
| 計画との差 | 平滑化した体重と計画線の差 ±0.5 kg以内 | 高 | 中（計画線自体が直線近似） | 採用 |
| 目標到達の見込み | 現在のペースを延長 | 中 | 低（減量は次第に鈍化するため楽観的になりやすい） | 採用（信頼度 低、注記つき） |
| 記録と体重変化の整合 | 記録上の収支と「体重変化×7,700 kcal/kg」の差が1日300 kcal以内 | 中（摂取の記録漏れや基礎代謝推定のずれに気づける） | 低（7,700 kcal/kgは概算、初期は水分変動が大きい） | 条件付き採用（14日以上のデータ） |
| 家庭血圧（7日平均） | 日本高血圧学会2019の家庭血圧分類：正常 <115/75、正常高値 115〜124/<75、高値 125〜134/75〜84、高血圧 ≥135/85 | 高 | 高（ガイドライン基準、平均で誤差低減） | 採用 |
| BMI | 日本肥満学会：18.5未満 低体重、25以上 肥満 | 中 | 高（ただし筋肉量が多い人は過大） | 採用 |
| 内臓脂肪レベル | オムロンの判定：1〜9 標準、10〜14 やや高い、15以上 高い | 中 | 低（機器独自の推定値、メーカー間で基準が異なる） | 採用（信頼度 低） |
| 安静時心拍の目安 | 成人60〜100 bpm、80超は高め。10 bpm上昇ごとに全死亡リスク約9%増（CMAJ 2016 メタ解析）。前3週比+5 bpm以上を上昇とする | 中（疲労・体調・体力の変化の目安） | 中（専用の安静時心拍ではなく、日中の心拍の下位10%で代用） | 採用 |
| 睡眠時間（7夜平均） | 睡眠ガイド2023：成人6時間以上。7〜9時間を推奨域 | 高 | 中（ウォッチの推定、7夜平均の誤差は約±19分） | 採用 |
| 睡眠の規則性 | 睡眠中央時刻のばらつき（標準偏差）30分以内。睡眠の規則性は睡眠時間より死亡リスクとの関連が強い（Sleep 2024, UK Biobank） | 中〜高 | 中（研究のSRIを単純化した代替指標） | 採用 |
| 歩数（7日平均） | 身体活動ガイド2023：成人 約8,000歩、高齢者（65歳以上）約6,000歩。死亡リスク低下は60歳未満で8,000〜10,000歩、60歳以上で6,000〜8,000歩で頭打ち（Lancet Public Health 2022） | 高 | 高 | 採用 |
| 血中酸素（平均） | 95%以上が目安 | 低（健康な人では変化がなく行動につながらない） | 低（手首計測の精度） | 不採用（Home画面の既存表示のみ） |
| 体年齢 | 機器独自の算出 | 低 | 低（算出方法が非公開） | 不採用 |
| 総合スコア（1つの点数） | 重み付けに根拠がない | 中 | 低 | 不採用（指標ごとに表示） |
| HRV・VO2max | 健康指標として有用 | 高 | ― | 現在は取り込み対象外。Apple Health取り込みに追加すれば候補 |

## 3. シミュレーションによる妥当性評価

真値を決めた合成データにノイズを加えて4,000回推定し、どの計算方法なら判定に使えるかを確認しました（`scripts/health_metrics_simulation.py` で再現できます）。

**減量ペース**（真値 −0.50 kg/週、日々の変動 SD 0.6 kg、25%の日は未測定）

| 推定方法 | 誤差（RMSE） |
|---|---|
| 前日との差×7 | 5.86 kg/週 |
| 7日前の1回との差 | 0.84 kg/週 |
| 週平均どうしの差 | 0.40 kg/週 |
| 14日間の回帰 | 0.34 kg/週 |
| **28日間の回帰（採用）** | **0.11 kg/週** |

28日回帰の±2SE区間は真値を94%含み、減少を99%検出しました。区間が0をまたぐときは「変化ははっきりしません」と表示します。

**脂肪の割合**（真値75%、体脂肪率の測定誤差 SD 0.8ポイント）

| 期間・減量幅 | 推定の80%区間 |
|---|---|
| 4週・2 kg | 44%〜111%（使えない） |
| 8週・4 kg | 64%〜87% |
| 12週・6 kg | 69%〜81% |

→ 直近8週間で3 kg以上減った場合だけ判定し、信頼度は「低」と表示します。

**家庭血圧**（真値 128 mmHg）：「高値血圧」に正しく分類できた割合は3日平均67%、5日平均77%、7日平均83%。→ 3日未満は判定せず、5日未満は「分類が変わる可能性」を併記します。

**睡眠・歩数**：7日平均の誤差は睡眠±19分（夜ごとのSD 50分）、歩数±1,133歩（日ごとのSD 3,000歩）。判定の境界付近以外では十分安定します。

## 4. 表示ルール

- 状態は「良好・注意・要見直し・データ不足」の4つ。データ不足のときは、必要な記録を具体的に示す。
- すべての指標に「目安（根拠）」と「信頼度（高・中・低）」を表示する。
- サマリー文には減量ペースと、「要見直し」の指標を最大3文まで出す。
- 診断ではないことと、気になる値が続くときは医療機関に相談することを明記する。
