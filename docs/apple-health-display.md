# Apple Health表示

ダッシュボード「ウォッチ・ヘルスケアの記録」で利用者・日付・記録元を選び、
既存のGET /api/apple-health/samplesから保存済み6項目を読み出す。
インポートAPI、DB、体組成の既存表示、健康相談への入力は変更しない。

- 日付は閲覧端末のタイムゾーン。翌日0時を排他的上限にする。
- 1,000件ずつ全ページ取得。50,000件超過は表示を中止し不完全な合計を出さない。
- 歩数・距離・エネルギーは開始日帰属で合計。距離は保存単位mからkmへ表示換算。
- 心拍・酸素は単純標本平均。測定間隔で重み付けしない。推移は点で表示し欠測を線で補わない。
- 睡眠は選択日の区間にクリップ。覚醒・in_bedを除く区間の和集合で睡眠時間を算出。
  一晩単位ではなく暦日表示。段階が重なる場合もグラフでは元区間を残す。
- 記録なしはダッシュ表示。記録元は一つずつ選ぶ。unknown内の異なる機器の重複は識別できない。
- グラフはタップ/スライドで日時・値を表示。詳細は100件ずつ追加表示する。
- 手動再読み込み、利用者・日付変更時に取得。ポーリングや追加のディスク書込なし。
- 読み込み開始とエラー時に旧表示を消し、古いリクエストの応答を破棄する。

検証: tests/apple-health-view.cjs（区間重複・日境界・欠測・単位換算・
1,001件ページング・DOM描画・取得失敗時のクリア）。実NAS/iPhoneでの表示確認は別途。
添付された個人の健康ログはリポジトリに含めない。
