# 0.3.19 減量計画・AI支援 改修計画

## ゴール

- 「代謝変化を含む試算」が直線の目標線とずれる理由を画面上で説明し、到達見込み・差・必要な平均エネルギー差を数値化する。
- 週次計画にAI分析ボタンを追加し、現在の計画・試算・週次実績・安全ガードを渡して、目標達成へ向けた調整候補（期間、標準摂取、生活活動、運動）を具体的に整理する。
- 計画入力を「標準モデル」中心に再構成し、毎日の入力を必須にしない。身長・年齢・計算条件・体重から推定安静時消費を算出し、生活活動係数と標準運動から総消費を見積もる。
- 朝食・昼食・夕食・間食の文章から、設定済みAIで摂取カロリーを試算する。結果は自動確定せず、利用者が確認後に「その日の摂取」または「標準摂取」へ反映できる。
- 既存DB・バックアップと後方互換を維持し、0.3.19としてCI・QPKGビルド・Releaseまで完了する。

## 計算モデル

- 安静時消費: 既存の Mifflin–St Jeor 推定を継続。
- 生活活動: 意図的な運動を除いた生活活動係数（PAL）として扱う。
- 標準運動: 種類プリセットのMET値と分/日を入力し、標準MET換算式から追加消費を推定する。基礎分との二重計上を避けるため、計画では `max(MET - 1, 0)` の正味分を加算する。
- 試算: 日ごとに体重に応じて安静時消費・標準運動消費を更新する。既存の追加消費低下シナリオは感度分析として残す。
- 到達判定: 目標までに必要な平均差、現在の標準モデルでの初日総消費、推定摂取、目標日の試算体重、目標との差を返す。
- 下限ガード: 既存の自動目標下限を維持し、目標達成のために下限を破る数値を「推奨値」として自動設定しない。

## UI

1. 週次グラフの見出し横に説明アイコンと「AIで達成方法を分析」ボタン。
2. グラフ下に「試算の意味」カード:
   - 直線 = 目標日から逆算した比較線
   - 試算 = 標準摂取・生活活動・標準運動・体重変化・追加低下仮定を使う簡易シナリオ
   - 目標日試算体重、差、必要平均エネルギー差
3. 計画フォームは意味が分かるラベルへ変更:
   - 生活活動レベル（選択式）
   - 標準運動の種類
   - 標準運動 分/日
   - 標準摂取 kcal/日
   - 追加消費低下の感度 %
   - 計算プレビュー
4. 食事AI試算:
   - 日付、朝食、昼食、夕食、間食
   - AI試算結果と内訳/前提
   - 「その日の摂取に反映」「標準摂取に反映」
   - AI推定は必ず確認後に既存フォームへ反映し、自動保存しない。

## AI・プライバシー

- 既存の明示設定済みAI接続先だけを利用する。
- 計画分析は既存の集約済み健康コンテキストを利用し、氏名・利用者ID・全履歴は送らない。
- 食事試算は入力した食事文章だけを送る。Web検索が可能な接続先には必要時の参照を促すが、QnapSelfCare自身が任意URLへアクセスする機能は追加しない。
- AI回答は助言候補であり診断・治療・薬調整ではないことを維持する。
