# 健康サポート・設定ページとAI相談の再構成

## 見直し前の課題

| ページ | 課題 |
|---|---|
| 健康サポート | 6枚のカードが縦一列に並び、スマホで約3,500px。毎日の入力欄が折りたたみの中にあり、長い説明文と並んでいた。食事メモとAIのカロリー試算が離れた場所にあった。 |
| 設定 | iPhone連携の受信デバッグが先頭で、利用者やAIの設定が中ほどにあった。HomeHub移行・JSON復元など、まれにしか使わない操作が普段の設定と同じ並びにあった。スマホで約4,500px。 |
| AI相談 | 質問の例がない。送る情報が文章でしか分からない。回答はプレーンテキストで、続けて質問できない。評価指標が文脈に入っていない。 |

## 新しい構成

ページ上部のタブで切り替えます（選んだタブは端末ごとに記憶）。フォームはすべてDOMに残るため、入力途中の内容は失われません。

**健康サポート**
1. 今日の記録：いまの状態（タイル）、今日の活動と摂取（入力欄を常に表示し、詳細と説明は折りたたみ）、食事（メモ＋AIカロリー試算）、エネルギーの推移
2. 減量計画：計画グラフ・試算・週次実績・計画の作成と履歴
3. AIに相談
4. 身体情報・目標：身体情報と目標／判定に使う参考線／実行する計画

**設定**：利用者／AI／データ取込（OMRON引き継ぎ・CSV・JSON）／バックアップ／連携（iPhoneショートカット・共通Bluetooth）／システム（診断・更新）。JSON復元とHomeHub移行には「特別な場合だけ使う」ことを明記しました。

Homeのダイエットカードにある「計画を見る」は、健康サポートの減量計画タブを直接開きます。

## AI相談

- テーマ：体調・記録／運動・睡眠（新規）／食事／減量の目標／計画の見直し。テーマごとに質問の例を3つ表示。
- 「AIに送る情報」に送信する項目を一覧表示。
- 続けて質問すると、直前のやり取り（最大3往復、回答は各4,000文字まで）を一緒に送ります。「新しい相談にする」で消去。
- 回答はMarkdown（見出し・箇条書き・太字）を表示。HTMLとして解釈せず、テキストノードだけで組み立てます。
- 回答をコピー／計画欄にコピー（身体情報・目標タブへ移動）。
- AIへの文脈にHome画面の評価指標（減量ペース・家庭血圧・睡眠・歩数など、状態と根拠）を追加。回答の形式を「要点／根拠になったデータ／提案（最大3つ）／注意」に統一。
- QnapAssistantの非同期相談（受付ID・進捗表示・キャンセル・再接続）はそのまま使えます。sessionStorageには受付IDと利用者IDだけを保存し、質問や回答は保存しません。
